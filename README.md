# DeFi Market Risk Report

Independent, evidence-based risk intelligence for DeFi lending markets.

## Product principle

**Measure → Explain → Simulate → Let the user choose.**

This repository is for the standalone **DeFi Market Risk Report** product. It is intentionally isolated from other Proof & Signal repositories.

The product is designed as decision-support analytics, not personalized investment advice and not custody or discretionary asset management.

## Status

Initial repository bootstrap. Product build work continues through feature branches and pull requests.
